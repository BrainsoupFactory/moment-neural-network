# Release notes (mnn)

## Version 0.2.0

- Added Torch-first parallel core APIs for Dawson approximation, MNN core functions, and moment activations.
- Added Pythonic Torch NN, models, and SNN APIs while keeping legacy entrypoints available.
- Added the single-file `mnn.utils.training_tools_api` entrypoint for training utilities.
- Added migration documentation and test design/result documentation for the new API surface.

## Version 0.1.0

First version ready to use.
